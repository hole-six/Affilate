✅ CẦN LÀM NGAY BÂY GIỜ (3 BƯỚC):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BƯỚC 1: Deploy code mới lên VPS
   cd /var/www/iviback
   git pull
   npm install
   npm run build
   pm2 restart nextjs-app

BƯỚC 2: Cấu hình Lazada Dashboard  
   1. Đăng nhập: https://affiliate.lazada.vn
   2. Settings → Postback URL → Create New
   3. Name: iviback Order Tracking
   4. Event: Order  
   5. URL: Copy URL ở trên ☝️
   6. Save → Run Test

BƯỚC 3: Verify hoạt động
   # Test endpoint
   curl "https://iviback.vn/api/webhooks/lazada/postback?order_id=test"
   
   # Xem logs
   pm2 logs nextjs-app | grep LAZADA

🔥 LỢI ÍCH POSTBACK VS CRON JOB:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Trước (Polling):        Sau (Postback):
✗ Chạy mỗi 30 phút     ✓ Realtime (D+1 từ Lazada)
✗ Tốn CPU/RAM          ✓ Chỉ chạy khi có đơn
✗ Có thể bỏ sót        ✓ Không bỏ sót
✗ Delay 0-30 phút      ✓ Delay tối đa 24h
